# atcoder-cpp

AtCoderの記録とかその他C++学習関係のファイル置き場

奇跡的にこれを見てくれている人がいるかもしれない可能性を考慮して.bash_functionsの使い方をまとめます。<br>
競プロ学習に便利なファイル管理コマンドなど<br>
wslとかで`~/work/cpp-study`になっている前提になってます。<br>

### `run`コマンド

今いるディレクトリのmain.cppをコンパイルして実行します。<br>
デフォルトだとmainファイルが出現する。<br>
第一引数で指定したファイルをrun<br>
第二引数で指定したファイル名にコンパイル<br>

### `mkabc`コマンド
abcで書いたファイルを管理するディレクトリ構造を作成します。<br>
各問題ごとに、自動的にmain.cppが作成される。<br>
第一引数でコンテストの番号？を指定<br>

### `next`/`prev`コマンド
mkabcで作った構造体の中で、問題（a問題とかb問題とか）のディレクトリを移動することができます。<br>
`next`は次の問題、`prev`は前の問題に移動する。
